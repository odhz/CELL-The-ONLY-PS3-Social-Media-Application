# CELL 1.1.6 Hotfix 3 (1.1.6.3) Patch Notes: no more freezing on updates

## Fixed

- **Updating froze the PS3** at "Installing...". CELL no longer installs updates by itself: it downloads them to the PS3's package folder and shows the steps to install them from Package Manager, like before 1.1.6. Your account, posts and friends are always safe on the server.
- Copies of CELL 1.1.6.1 and 1.1.6.2 won't try to install this update by themselves either: they show the Package Manager steps too, so nobody freezes on the way to it.
- **"kkk" and "kkkkkkk" are laughter, not hate speech.** Brazilian, Spanish and Portuguese players' "kkkk" (like lol) is no longer caught by the word filter. The Klan by name still is.

## For staff

- **Replace the published package** (Updates → PS3 app) puts a new file under the release that's already published, or fixes a mistyped version number (for example 1.6.1.2 instead of 1.1.6.2). PS3s are only ever offered a version higher than their own.
